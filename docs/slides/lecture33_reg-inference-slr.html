Activity: Average Home Price between Seattle and Portland

Suppose you’re interested in comparing average home price between Seattle and Portland

  • You randomly sample \(n_1=50\) Seattle homes, and find \(\bar{x}_1=0.95M\), \(s_1=0.15M\).
  • You randomly sample \(n_2=35\) Portland homes, and find \(\bar{x}_2=0.70M\), \(s_2=0.35M\).


With Neighbor(s): Choose a question below and work through it on the board.

Confidence Intervals

  • Find a 80% confidence interval for the difference in average home price.

  • Are we 80% confident there’s actually a difference?

Hypothesis Testing

  • You’ve heard there’s no difference between Seattle and Portland!

  • Test your claim using a hypothesis test (with a significance level of \(\alpha = 0.01\)).

Answer Key: Confidence Intervals

With independent samples of size \(n_1>30\), \(n_2>30\), we can use the t-distribution approximation method.

qt(0.90, df= min(50-1,35-1))
[1] 1.306952
sqrt(0.15^2/50 + 0.35^2/35)
[1] 0.06284903

\[ \begin{align*} (\bar{x}_1-\bar{x}_2) \pm t^*\times \sqrt{\frac{s_1^2}{n_1}+\frac{s_2^2}{n_2}} &= (.95-.70) \pm 1.307 \times 0.06285\\ & = (0.1679, \ 0.3321) \end{align*} \]

Thus, at the 80% confidence level, we think there is a difference in average home price between Seattle and Portland.

Answer Key: Hypothesis Testing

  1. Hypotheses: \(H_0: \mu_1 -\mu_2 = 0 \quad H_a: \mu_1-\mu_2 \neq 0\)

  2. Assess Conditions (on previous slide)

  3. Compute test statistic under \(H_0\) \[t = \frac{(\bar{x}_1 - \bar{x}_{2})-(\mu_1-\mu_{2})}{\sqrt{\frac{s_1^2}{n_1}+\frac{s_2^2}{n_2}}} = \frac{(.95-.70)-(0)}{\sqrt{\frac{0.15^2}{50} + \frac{0.35^2}{35} }} = 3.978 \]

  1. Calculate p-value
2*(1-pt(3.978,df=min(50-1,35-1)))
[1] 0.0003448846
  1. Conclude: We reject the null hypothesis (at the \(\alpha = 0.01\) level), in favor of the hypothesis that Portland and Seattle have different average home prices.

Simple Linear Regression

Review of Simple Linear Regression

We’ve used linear models to analyze the relationship between two quantitative variables

\[ y = \beta_0 + \beta_1 x + \epsilon \]

  • \(\beta_0\) and \(\beta_1\) are fixed numbers in our population model
  • \(\beta_0\) represents the intercept of a line
  • \(\beta_1\) represents the slope of a line

Performing least squares regression gives us our best guess at this model by providing estimates \(\widehat{\beta}_1\) and \(\widehat{\beta}_2\) based on our sample data:

\[ \widehat{y} = \widehat{\beta}_0 + \widehat{\beta}_1 x \]

Linear Models in R

  • To fit a linear model in R, we use the lm() function
my_mod <- lm(y ~ x, data = my_data)

Statistical Inference for Regression

  • We can fit a linear model to any data set we want, but if we just have a sample of data, any trend we detect doesn’t necessarily demonstrate that the trend exists in the population.

  • Goal of Inference: Use statistics calculated from data to make inferences about parameters

Parameters: \(\beta_0\) (intercept) and \(\beta_1\) (slope)

\[ y = \beta_0 + \beta_1 x + \epsilon \]

We won’t ever know the true values of these parameters. So we estimate them based on a least squares model in the sample:

\[ \widehat{y} = \widehat{\beta}_0 + \widehat{\beta}_1 x \]

Statistics: \(\widehat{\beta}_0\) (intercept) and \(\widehat{\beta}_1\) (slope)

Theory-Based Inference for Simple Linear Regression

Hypothesis Tests for Slope

\[\text{Population Model: } y = \beta_0 + \beta_1 x + \epsilon\]

\[\text{Sample Model: } \widehat{y} = \widehat{\beta}_0 + \widehat{\beta}_1 X \]

\[H_0: \beta_1 = 0 \qquad H_a: \beta_1 \neq 0\]

  • We’d like to use \(\widehat{\beta}_1\) to do this hypothesis test
    • Need to know the mean, standard error, and shape of the sampling distribution for \(\widehat{\beta}_1\)

Under the LINE conditions (we’ll check these soon), \(\widehat{\beta}_1\) is:

  • Approximately normally distributed
  • Has mean \(\beta_1\)
  • Has a standard error of:

\[ \color{red}{SE(\widehat{\beta}_1) = \sqrt{\frac{1}{n-2} \frac{\sum_{i =1}^n (y_i - (\beta_0 + \beta_1 x_i) )^2}{\sum_{i=1}^n (x_i - \bar x)^2}}} \] (Don’t memorize this!)

Hypothesis Tests for Slope

\[H_0: \beta_1 = 0 \qquad H_a: \beta_1 \neq 0\]

Under the LINE conditions, \(\widehat{\beta}_1\) is:

  • Approximately normally distributed

  • has mean \(\beta_1\)

  • Has a standard error of:

\[ SE(\widehat{\beta}_1) = \sqrt{\frac{1}{n-2} \frac{\sum_{i =1}^n (y_i - (\beta_0 + \beta_1 x_i) )^2}{\sum_{i=1}^n (x_i - \bar x)^2}} \]

  • In practice, we estimate \(\beta_0, \beta_1\) in the formula using \(\widehat{\beta}_0, \widehat{\beta}_1\), giving \(\widehat{SE} (\widehat{\beta}_1)\)

  • We perform a hypothesis test of \(H_0: \beta_1 = 0\) using the standardized t-statistic

\[ \text{t-statistic} = \frac{\textrm{sample stat}- \textrm{null value}}{\widehat{SE} (\widehat{\beta}_1)} = \frac{\widehat{\beta}_1 - 0}{\widehat{SE} (\widehat{\beta}_1)} \]

  • The \(t\)-statistic follows a \(t\)-distribution with \(n-2\) degrees of freedom.

  • We can use the pt() function to calculate the corresponding p-value

Confidence Intervals for Slope

We create a confidence interval for \(\beta_1\) using

\[ \textrm{sample stat} \pm \underbrace{t^*}_{\text{critical value}} \cdot \widehat{SE} (\widehat{\beta}_1) \quad = \quad \color{red}{\widehat{\beta}_1 \pm t^* \cdot \widehat{SE} (\widehat{\beta}_1)} \]

We use the critical values from a \(t\)-distribution with \(n-2\) degrees of freedom!



  • Can we do hypothesis tests and get confidence intervals for \(\beta_1\) without tedious calculation?
    • Yes! Using the lm() and get_regression_table() functions in R.

Conditions for Theory-Based Inference

LINE Conditions

To do theory-based inference for regression, we require the LINE conditions we talked about way back in week 4!

  1. Linearity: The relationship between explanatory and response variables must be approximately linear
    • Check using scatterplot/residual plot
  1. Independence: The observations should be independent of one another
    • Consider sample design and data context
  1. Normality: The distribution of residuals should be normally distributed
    • Histogram of residuals
    • Q-Q plot of residuals
  1. Equal Variability: Variance of residuals should be roughly constant across data set
    • Check using residual plot.

These make up the LINE Conditions (Linearity, Independence, Normality, Equal Variability)

1) Linearity

Linearity: The relationship between explanatory and response variables must be approximately linear

  • Points should be evenly distributed above and below the regression line at each “slice” of X

  • Some potential outliers with high page counts…

  • But this mostly looks okay!

2) Independent Observations

Independence: The observations should be independent of one another.

  • Hard to know if any two theses have dependence … but not totally unreasonable

3) Normality (of Residuals)

Normality of Residuals: The distribution of residuals should be normally distributed

  • Distribution appears somewhat right-skewed, with a notable potential outliers on the right.
  • This provides some evidence residuals are not Normally distributed.

4) Equal Variability (of Residuals)

Equal Variability: Variance of residuals should be roughly constant across data set.

  • Residuals appear to have constant variability between 1980 and 2020
  • However, theses prior to 1980 appear to have more spread

LINE Conditions: Recap

  • Linearity and Independence seem to be reasonably met…

  • but Normality and Equal Variance do not



  • Are we unable to do inference???
    • Fear not! We can get around this with the bootstrap!

Inference with Bootstrap

Bootstrap can get around Normality and Equal Variance! (with larger \(n\))

When Normality and Equal Variance do not hold, we can use the bootstrap for correct inference!

  • But we do need the sample size \(n\) to be larger than usual.

  • You should feel okay about this with a sample size of at least a couple hundred

Hypothesis Tests

\[H_0: \beta_1 = 0 \qquad H_a: \beta_1 \neq 0\]

Even without Normality and Equal Variability of the residuals, the standardized statistic

\[ Z = \frac{\widehat{\beta}_1 - \beta_1}{\text{Bootstrap $\widehat{SE}$}} \]

is approximately standard normal (i.e., mean 0 and SD 1) as \(n\) gets large enough.

  • This means we can use pnorm() to get our p-values!
    • The bootstrap is helping us estimate the SE for our z-score.
    • We need to use the bootstrap because we can’t trust the lm() theory-based SE estimates when these assumptions are violated.
  • We could go fully simulation-based and avoid even assuming that \(Z\) is approximately Normal - this just requires extra coding.

Hypothesis Tests

\[ H_0: \beta_1 = 0 \qquad H_a: \beta_1 \neq 0 \qquad \qquad Z = \frac{\widehat{\beta}_1 - \beta_1}{\text{Bootstrap $\widehat{SE}$}} \]

  1. Gather bootstrap samples…
boot_slope <- theses_samp %>% 
  select(n_pages, year) %>%
  rep_sample_n(nrow(theses_samp),
               replace = TRUE, reps = 1000) %>%
  group_by(replicate) %>%
  summarize(slope = get_regression_table(lm(n_pages ~ year))$estimate[2])
  1. Calculate the bootstrapped SE…
bootstrap_se <- sd(boot_slope$slope)
bootstrap_se
[1] 0.243737
  1. Calculate z-score under the null (\(\widehat{\beta}_1=-0.61\) is the original slope)…
z <- (b1 - 0) / bootstrap_se
z
     year 
-2.502698
  1. Calculate the p-value (2-sided test)…
p_value <- 2*pnorm(z)
p_value
      year 
0.01232507

We reject \(H_0\) at the 0.05 level! (But not at the 0.01 level)
