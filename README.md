## [https://megan-k-ayers.github.io/stat141-fall26/](https://megan-k-ayers.github.io/stat141-fall26/)

This repository contains source code for the course website for STAT 141: Introduction to Probability and Statistics at Reed College, Fall 2026.

The website was created with Quarto, adapted from the website Professor Grayson White previously developed for the course (thank you Grayson!). Much inspiration, styling, and formatting was drawn from UC Berkeley's [Stat 20 website](https://www.stat20.org/).
