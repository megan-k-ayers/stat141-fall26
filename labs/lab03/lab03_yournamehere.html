Exercise 1: Winfall

In 2003, the Michigan Lottery had a game called Winfall. For each ticket, you would pick six numbers between 1 and 49. Michigan Lottery would draw a six numbers: if you had all six numbers on your ticket, you won the jackpot. If you guessed fewer numbers, you won smaller amounts. If nobody won the jackpot for a while, there was a “roll-down,” where on the next drawing, as long as no one had a ticket with all six numbers, the jackpot cash flowed into the lesser tiers of winners. Roll-downs happened every six weeks or so, and in these cases, tickets with 5 winning numbers won $25,000, tickets with 4 winning numbers won $1000, and tickets with 3 winning numbers won $50.

A man named Jerry Selbee discovered a flaw (or, opportunity) in the math behind this roll-down structure. Mathematically, we expect the average winnings per ticket in this setup to be about $2.31 (we’ll learn why and what this formally means later in the semester). Importantly, a ticket only cost $1, meaning that on average, a ticket-buyer should expect to earn $1.31! For this problem, imagine we’re in Jerry’s shoes and deciding how to use this information.

(I am not claiming it is a good idea to go buy a bunch of lottery tickets! This particular instance was an anomaly that was quickly corrected when discovered by the Michigan Lottery. Read more about it in this article: https://highline.huffingtonpost.com/articles/en/lotto-winners/, or watch the movie based on it.)

The function below simulates the lottery process. For a given number of tickets you purchase (n), it returns your profit across all tickets (net winnings - cost of the tickets). This code uses several R concepts we haven’t learned, so don’t worry if they are unfamiliar - feel free to treat it like a black box.

buy_tickets <- function(n) {
  
  # Draw our n tickets (assuming random selection of the numbers)
  your_tickets <- replicate(n, sample(1:49, 6), simplify = FALSE)
  
  # Draw the winning ticket
  winning_ticket <- sample(1:49, 6)

  # For each of our n tickets, calculate how many of its numbers are in the
  # winning ticket
  wins <- sapply(your_tickets, function(a) sum(a %in% winning_ticket))
  
  # If 3 numbers are in the winning ticket, a ticket wins $50. If 4 numbers are
  # in the winning ticket, a ticket wins $1000. If 5 numbers are in the winning
  # ticket, a ticket wins $25000. Otherwise, we win $0. We
  # subtract the price of the tickets from our winnings to get our profit.
  profit <- sum(wins == 3) * 50 + sum(wins == 4) * 1000 +
    sum(wins == 5) * 25000 - n
  
  return(profit)
  
}
